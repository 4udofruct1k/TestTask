# Дом на двоих

Приложение на двоих: главная с плитками, общие разделы «Покупки», «Готовка»,
«Питание» и личный «Бюджет». Бюджет офлайновый, у каждого свой и из телефона
не уходит. Покупки, готовка и остатки продуктов сводятся между двумя
телефонами раз в сутки через функцию в Яндекс Облаке. Упаковка в APK через
Capacitor.

## Источник истины

[`BUDGET_SPEC.md`](BUDGET_SPEC.md) — спецификация бюджета: домен и инварианты,
расчётный движок, экраны, хранилище, сборка. Это источник истины, а не пожелание.
[`HOUSEHOLD_SPEC.md`](HOUSEHOLD_SPEC.md) — общие разделы: план питания, события,
покупки, готовка, сводка, облако.
[`cloud/README.md`](cloud/README.md) — настройка облака по шагам, с телефона.
[`CLAUDE_CODE_PROMPT.md`](CLAUDE_CODE_PROMPT.md) — порядок работы по шагам.
[`design/mockup.html`](design/mockup.html) — прототип экранов, эталон вёрстки.
[`GUIDE.md`](GUIDE.md) — как пользоваться приложением, на пять минут.

## Стек

| Слой | Решение |
|---|---|
| Сборка | Vite |
| UI | React + TypeScript (strict) |
| Состояние | Zustand |
| Графики | Собственный SVG |
| Даты | Своё, разбор строк |

UI-китов нет. Оформление на CSS-переменных из 3.9, шрифт Golos Text лежит
в бандле и с сети не грузится.

## Структура

```
src/
  domain/      типы, деньги, даты, валидатор инвариантов   → Часть 1
  engine/      чистые расчёты                              → Часть 2
  storage/     файл, атомарная запись, бэкапы, миграции    → Часть 4
  store/       Zustand: документ, общие данные, интерфейс
  platform/    Capacitor: файлы, pause, статус-бар, Share, сеть → Часть 5
  ui/          экраны, компоненты, графики, токены темы    → Часть 3
  ui/household/  главная с плитками, Покупки, Готовка, Питание
  household/   план питания, события, покупки, готовка, сводка → HOUSEHOLD_SPEC
  dev/         подставной документ на полгода истории
cloud/
  src/         облачная функция: приём очереди, Document API
  dist/        собранный index.js и function.zip для загрузки
scripts/plan/  рацион в HTML и сборка из него plan.json
tests/
android/       проект Capacitor
```

Жёсткое правило: `engine/` не импортирует ничего из `ui/`, `storage/` и `store/`,
а `domain/` и `engine/` не знают про конструктор `Date`. `household/` тоже без
часов, файлов и экрана: тот же код собирается в облачную функцию. Всё это
проверяется тестом `tests/rules.test.ts`, а не глазами.

## Разработка

```
npm install
npm run dev          # http://localhost:5173
npm test             # 436 тестов
npm run typecheck
npm run build:cloud  # облачная функция → cloud/dist/
```

Флаги режима разработки (только в `npm run dev`):

- `?demo=1` — подставной документ на полгода истории: дашборды есть на чём проверить.
- `?fresh=1` — стереть данные, вместе с общими, и посмотреть первый запуск.

Данные в браузере лежат в `localStorage`, на устройстве — в приватной директории
приложения (Capacitor Filesystem, `Directory.Data`).

## Веб-версия на «Домой»

Собранная веб-версия лежит в `docs/` и раздаётся GitHub Pages:
**https://4udofruct1k.github.io/TestTask/**

Открыть ссылку в Safari на айфоне → «Поделиться» → «На экран „Домой"».
Появится иконка, приложение откроется без браузерной строки и после первого
захода работает без сети. Это не сборка из App Store: данные лежат
в хранилище браузера, нативных плагинов нет — но офлайн, иконка
и полноэкранный режим есть.

Обновить выложенное:

```
npm run build:pages     # пересобирает docs/
git add docs && git commit && git push
```

## Сборка APK

Нужны JDK 21, Android SDK Platform 35 с Build-Tools и `ANDROID_HOME`, Node 20+.

```
npm run android:debug      # build + cap sync + assembleDebug
```

APK окажется в `android/app/build/outputs/apk/debug/app-debug.apk`.

Release требует подписи. Keystore создаётся один раз:

```
keytool -genkey -v -keystore budget.keystore -alias budget \
        -keyalg RSA -keysize 2048 -validity 10000
```

Рядом кладётся `android/keystore.properties` (в `.gitignore`, в репозиторий
не попадает никогда):

```
storeFile=/абсолютный/путь/budget.keystore
storePassword=…
keyAlias=budget
keyPassword=…
```

После этого `npm run android:release` подпишет сборку.

**Потерянный keystore означает, что обновить установленное приложение нельзя.**
Android не поставит APK с другой подписью поверх существующего, останется только
удалить — а удаление вычищает приватную директорию вместе со всей историей
бюджета. Keystore хранится так же надёжно, как экспорты бюджета.

## Версии

`versionCode` растёт на единицу с каждой сборкой, которая ставится на телефон.
`versionName` — человеческая строка, она же `APP_VERSION` в `src/version.ts`
и `appVersion` в конверте файла. Любое изменение `schemaVersion` обязано
поднимать `versionName`: иначе по экспортному файлу не понять, какая сборка
его написала.

## Тесты

Приёмка — кейсы из спецификации, каждый отдельным тестом с теми же числами:

- `tests/engine.test.ts` — К1…К11 из 2.15;
- `tests/storage.test.ts` — К1…К6 из 4.10;
- `tests/engine-pitfalls.test.ts` — медиана против среднего, остаток цикла SPREAD,
  ставка накопления за период;
- `tests/income-tax.test.ts` — необязательное удержание налога и миграция 3→4;
- `tests/dates.test.ts`, `tests/money.test.ts`, `tests/validate.test.ts` — домен;
- `tests/household.test.ts`, `tests/household-store.test.ts` — общие разделы:
  события, покупки, готовка, очередь и сводка;
- `tests/cloud.test.ts` — облачная функция поверх базы в памяти;
- `tests/rules.test.ts` — сторож жёстких правил.

Системные часы не мокаются нигде: `today` всегда приходит параметром, а часы
хранилища — интерфейсом `Clock`. Облако в тестах — та же функция поверх базы
в памяти, сеть не нужна.

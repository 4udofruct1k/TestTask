# Собранный APK

`budget-1.0.0-debug.apk` — debug-сборка для боковой установки, подписана
отладочным ключом Android. Для обновления поверх release-сборки не годится:
подписи разные, Android откажется ставить.

Файл лежит здесь только ради ссылки на скачивание. Обычное место сборки —
`android/app/build/outputs/apk/debug/`, и туда же кладёт результат
`npm run android:debug`. Если не хотите держать бинарник в истории,
удалите каталог: на сборку это никак не влияет.

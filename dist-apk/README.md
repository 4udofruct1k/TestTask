# Собранный APK

`dom-na-dvoih-2.0.0-debug.apk` — debug-сборка «Дома на двоих» для боковой
установки, подписана отладочным ключом Android. Ставится поверх прежнего
«Бюджета» (тот же `appId` и та же подпись) и сохраняет его данные. Для
обновления поверх release-сборки не годится: подписи разные, Android
откажется ставить.

Файл лежит здесь только ради ссылки на скачивание. Обычное место сборки —
`android/app/build/outputs/apk/debug/`, и туда же кладёт результат
`npm run android:debug`. Если не хотите держать бинарник в истории,
удалите каталог: на сборку это никак не влияет.
